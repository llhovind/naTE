Configuration Reference

All configuration keys in ~/.nate/config.ini, their types, defaults, and what they control.

Prefer the UI: Almost all settings are exposed in Edit → Preferences. Edit config.ini directly only for options not yet in the Preferences UI, or to script bulk changes.

File Format

The config file uses a simple INI format with [Section] headers and key = value pairs. Comments start with ; or #.

; ~/.nate/config.ini
[Appearance]
themeName = solarized-dark
fontSize = 14

[Behavior]
copyOnSelect = true

naTE writes a default config.ini to ~/.nate/ on first launch. You only need to set keys you want to override — unset keys use their built-in defaults.

[Appearance]

KeyTypeDefaultDescription
themeName string solarized-dark Name of the active color theme. Must match the filename (without extension) of a theme in the built-in set or in ~/.nate/themes/.
fontFamily string (system default) Monospace font family name. Empty string uses the system default monospace font.
fontSize integer 12 Terminal font size in points.
padding integer 4 Inset around the terminal canvas in pixels.
cursorStyle enum Block Cursor shape: Block, Bar, or Underline.
cursorBlink bool false Whether the cursor blinks.
tileLayout enum RowFirst Default tile layout direction for new windows: RowFirst or ColumnFirst.

[Behavior]

KeyTypeDefaultDescription
copyOnSelect bool true Automatically copy selected text to X11 primary selection on mouse release.
confirmCloseWindow bool true Show a confirmation dialog before closing a window with active sessions.
bellMode enum Visual Response to terminal bell (^G): None, Visual (flash), or Audible.
webSearchUrl string DuckDuckGo URL template for Edit → Web Search. The selected text is URL-encoded and substituted for {query}.
wordSelectRegex regex string [^\s]+ ECMAScript regex defining a "word" for double-click selection. The default selects any run of non-whitespace characters.
encoding string UTF-8 Character encoding for terminal I/O.

[Session]

KeyTypeDefaultDescription
autoRestoreSession bool false Restore the last saved session layout on launch.
sessionSaveInterval integer 300 Seconds between auto-saves. Set to 0 to disable auto-save.
defaultShell string (empty) Shell command for new PTY sessions. Empty uses $SHELL, falling back to /bin/sh.
defaultWorkingDir string (empty) Default starting directory. Empty inherits the directory naTE was launched from.
defaultLoginShell bool true Invoke shells as login shells by default (-l flag).
defaultEnvFilePath string (empty) Path to a .env-style file loaded for every new session.
defaultWrapMode bool true Whether new sessions start with wrap mode on. On (default): naTE behaves like a classic terminal — the shell's reported width matches the visible tile width, and long lines wrap at the tile edge. This is the most compatible mode and the right starting point for most users. Off: naTE reports ptyLineWidth columns to the shell, capturing long lines in full without truncation. The tile scrolls horizontally to reveal them. Switch to this mode when you work with wide output (e.g. broad git log graphs, wide DataFrames, long log lines) and want to see the full content without reflowing it. Toggle per-session at any time with the Wrap button in the tile title bar.
remoteEditorCommand string (empty) Editor command for Terminal → Edit Remote File. Empty uses $EDITOR. Use code --wait for VS Code.

[Terminal]

KeyTypeDefaultDescription
columns integer 80 Default terminal width in columns. This is what the shell reports as the terminal width.
rows integer 24 Default terminal height in rows.
scrollbackLines integer 100000 Maximum number of lines kept in the scrollback buffer per session.
ptyLineWidth integer 4096 The column width naTE reports to the shell when wrap mode is off. This is what programs like ls, git log, and colored output formatters use to decide where to truncate or wrap their output. A large value (the default 4096) tells the shell the terminal is very wide, so lines are captured in full rather than truncated at the visible tile edge. When wrap mode is on, naTE reports the actual tile pixel width in columns instead, and this setting has no effect. See also defaultWrapMode in [Session].

Command-Line Options

naTE accepts a small number of flags when launched from a terminal. These are useful for scripting, desktop launchers, or overriding the restore behavior for a single launch.

nate [--no-restore] [--restore-last-workspace]
FlagDescription
--no-restore Start fresh — suppress session restore for this launch even when autoRestoreSession = true is set in config.ini. Opens a single empty window. Takes precedence over --restore-last-workspace if both are given.
--restore-last-workspace Force session restore for this launch even when autoRestoreSession = false in config.ini. Useful in a desktop launcher when you want restore on demand rather than always.

Common patterns

Always restore on launch — set autoRestoreSession = true in config.ini.

Restore only when you ask — leave autoRestoreSession = false and create two desktop launchers: one plain (nate) and one with --restore-last-workspace.

Emergency clean start — run nate --no-restore when a corrupted restore file is causing a crash on startup.

Internal flag: --restore-instance N is used internally when naTE spawns a sibling process to take ownership of a prior instance's saved state. It is not intended for end-user use.

Data Files

The following files are written automatically by naTE and should not normally be edited by hand. They are listed here for reference and troubleshooting.

FileFormatContents
~/.nate/connections.json JSON All saved connection profiles. Edited via Connection → Connection Manager.
~/.nate/workspaces/*.json JSON Named workspace snapshots. One file per workspace. Managed via Connection → Workspace Manager.
~/.nate/workspaces/instance-restore-*.json JSON Auto-save snapshots. One file per instance. Overwritten on each save interval.
~/.nate/themes/*.yaml base16 YAML Custom color themes. Placed here manually. See Custom Themes.

Example config.ini

; ~/.nate/config.ini

[Appearance]
themeName    = gruvbox-dark
fontFamily   = JetBrains Mono
fontSize     = 13
padding      = 6
cursorStyle  = Bar
cursorBlink  = true

[Behavior]
copyOnSelect       = true
confirmCloseWindow = true
bellMode           = None
wordSelectRegex    = [^\s,;:'"()\[\]{}]+

[Session]
autoRestoreSession  = true
sessionSaveInterval = 120
defaultWorkingDir   = ~/Projects
defaultLoginShell   = true
remoteEditorCommand = code --wait

[Terminal]
columns       = 220
rows          = 50
scrollbackLines = 200000

Note: Setting columns = 220 globally means every new session will tell its shell that the terminal is 220 columns wide. For most users the default of 80 is fine; use a wider value if you regularly work with wide output (DataFrames, long log lines, etc.) and want naTE to capture it without truncation. You can always override per-connection profile.
