Complete shortcut reference. All shortcuts shown are for Linux; macOS users substitute Cmd for Ctrl where noted.

Shift+Ctrl+TNew Connection — open the New Connection dialog as a new Tab

Editing

ShortcutAction

Shift+Ctrl+VPaste from clipboard
Middle-clickPaste from X11 primary selection

Search Navigation

ShortcutAction
Enter / F3Jump to next search match
Shift+F3Jump to previous search match

Text Selection

ActionBehavior

Tips & Tricks

  • Quick tab open: Click the + button in any tile's title bar to open a new connection in that tile.
  • Search from selection: Select text, then press Shift+Ctrl+F — the search bar opens pre-populated with the selected text.
  • Scroll past output: Middle-click the scrollbar track to jump instantly to any position in the scrollback. Behavior is Window Manager dependent.
  • Stuck TUI? Press the AltScr button to force-switch back to the main screen buffer if a TUI crashes without cleaning up after itself.
  • Stuck colors? Use Terminal → Reset Terminal to clear all ANSI modes without losing your scrollback content.
